# Anabia's Story World

A fun kids website for young author **Anabia Noor** (grade 2) — meet Leo the fluffy Persian cat, play games, and celebrate her first storybook *Leo, Let's Go!*

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
